# Hito 2 (ACUS220 · Acústica Computacional con Python)

## Contexto

El objetivo del trabajo es entrenar un modelo de clasificación de escenas acústicas que sea capaz de distinguir entre escenas de interior, exterior y vehículos. Y posteriormente probarlo con grabaciones hechas manualmente.

Para el trabajo su utilizará la base de datos TUT Acoustic Scenes 2016 - Task 1 para el entrenamiento de la red neuronal.

## Avances

Para este hito se preparó el cuaderno de Jupyter donde se realizará el proyecto. Se completó la primera parte que consiste en hacer una exploración inicial de los datos, extraer las carácterísticas y entrenar el modelo.

## Trabajo pendiente

Preparar la parte 2, que consiste en subir grabaciones y probar la efectividad del modelo con ellas.

- Crear un entorno de conda utilizando environment.yml
- Ejecutar la primera celda del cuaderno para verificar que está todo instalado.
