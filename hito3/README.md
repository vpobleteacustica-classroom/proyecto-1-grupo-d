# Hito 3 (ACUS220 · Acústica Computacional con Python)

## Contexto

El objetivo del trabajo es entrenar un modelo de clasificación de escenas acústicas que sea capaz de distinguir entre escenas de interior, exterior y vehículos. Y posteriormente probarlo con grabaciones hechas manualmente.

Para el trabajo su utilizará la base de datos TUT Acoustic Scenes 2016 - Task 1 para el entrenamiento de la red neuronal.

## Avances

Se completó el cuaderno de Jupyter del proyecto, las novedades incluidas son las siguientes:
- Se desarrollo un segundo modelo que usa las 15 etiquetas.
- Se desarrollo una interfaz de tkinter que carga los audios de la carpeta *grabaciones* y puede comprobar qué porcentajes entrega de cada modelo.
- Se agregó una conclusión con los resultados obtenidos

## Trabajo inconcluso

- Ya fue mencionado en la conclusión agregada en el proyecto, pero en resumen, no se obtuvieron los resultados esperados al aplicar el modelo entrenado sobre las grabaciones que se hicieron manualmente, esto seguramente se debe a la diferencia de los audios usados para entrenar el modelo con los audios manuales. Hay diversas técnicas que se podrían usar para intentar mejorar el resultados, pero eso se escapa del alcance del proyecto
